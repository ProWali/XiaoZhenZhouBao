# 子 Agent 试玩

真人试玩只在关口做；每一轮改动之后，先让扮演不同玩家的子 Agent 玩一遍。

## 它管什么、不管什么

- **管**：会不会卡住、在哪里白跑、哪句话像程序写的、规则看不看得懂、玩完能不能讲出镇上发生了什么。这些都是看得见的行为，跟真人行为对得上就能用。
- **不管**：好不好玩、动不动人、值不值得买。子 Agent 不会真无聊，也不会真被打动，而且它跟写这个游戏的是同一类模型，口味接近。它说「感人」不算证据。

## 工具

- `scripts/debug/agent_play.gd`：无头跑真界面，把当前一屏所有看得见的字和能点的东西打成文字；每次调用都从新局重放全部点击，确定性。
- `scripts/tools/play.sh <会话目录> new <种子> | <编号>... | （空）`：子 Agent 只用这个。
- 会话目录（`user://agent_play/<名字>`）：`session.json`（点击）、`save.json`（存档，`replay_report.gd` 能读）、`transcript.md`（完整记录）、`notes.md`（子 Agent 的边玩边记）。
- **会话跑的时候不要改游戏代码**：重放靠点击的文字对得上，改了界面文字或模拟，正在跑的会话就重放不出来了。

## 规矩

- 子 Agent 看不到代码、策划案和数据表，只能运行 play.sh（`试玩须知.md` 原文贴进提示词，不让它去仓库里读）。
- 问卷玩完以后才发（跟真人一样）。
- 性格写成能照做的规矩（`性格卡.md`），不写形容词。
- 部分性格换模型跑（sonnet / opus），少一点「和我一个口味」。
- 报告只认能观察到的东西：无聊度曲线、卡住的地方、白跑的次数、原句。

## 校准

真人和子 Agent 在同一个种子上玩，比较两边的行为。子 Agent 复现得出真人的毛病，它的结论才可信；复现不出来，说明它在哪方面比真人「聪明」，读结果时要打折。
注意：子 Agent 跑的是当前代码，朋友玩的是 M4.1 包；第一周的镇子一样，之后因为平衡改动会走岔，比的是行为，不是逐步对照。

## 已知问题：子 Agent 被安全审查误拦
第 5 轮五局里断了三局，报错类型都是 `reasoning_extraction`。原因多半是提示词要它「写下我在想什么、为什么」。现在笔记那一栏改成「打算」，不要求写理由。断了的局照旧换个模型，从同一个会话接着玩。

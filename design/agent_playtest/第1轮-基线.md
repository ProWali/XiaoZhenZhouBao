- 新手性格复现了朋友的毛病：交谈命中率在同一个区间，提前收工的次数几乎一样（9、10 对 11、9），也都是在第 2、3 周进入空转。**新手性格可以当真人的替身用。**
- 跟真人不一样的地方：子 Agent 熬夜熬得少（读懂了「一周超过两次就丢上午」），所以丢掉的上午远少于真人。看「熬夜代价」不能用它。
- 子 Agent 读字比真人认真，这一点不用去校准；它们挑出来的文字问题，五局里多次撞上的就当真。

## 五局都提到的（按出现的局数排）

1. **没有 ★ 就不知道干什么，在空转里耗掉一两天**（5/5）。
2. **「谁会知道」推不出来**（老周、阿凯、小林）。牧师不知道自己门口贴的结婚预告，林子的主人不知道林子里有套子。拿某条料去问人，十几次都没加上章；能加章的反倒是随便聊碰巧撞上。代码上的原因：
   - 知情人里有 `random:n`，是随机撒的人；
   - 先掷「愿不愿意说」，后看「知不知道」，所以「含糊几句」既可能是知道不说，也可能是根本不知道，玩家分辨不出来。
3. **自称全名、自己招认**（5/5）。
4. **当面谈话不接这个人自己的事**（小林、老周、莉莉）：
   - 写信感谢的新郎，当面只问涨价；
   - 上门说「有事来找我」的人，真去找他，他却岔到天气上。
5. **路走不通**（4/5）：
   - 选题簿提示晚上去蹲守镇公所、邮局，可晚上这两处点不了；
   - 线头指向待在家里的人（家眷、寡妇），不说在哪，也找不到；
   - 来信说「来找我」的人不进线头页。
6. **报道编出没发生的事**（阿凯、老周）：
   - 「本报托人捎了话」「坚称自己清白」「某位寡妇对本报说」；
   - 线人说的料，写成了「本报看见的」。
7. **前后对不上**：
   - 写信退订的人，邮差却说她「对报道很满意」；
   - 人已经上门求过情，两周后还说他「好像还没读到」；
   - 自己给自己带话；
   - 两个人寄来一字不差的同一封信；
   - 受害者上门花钱求你别写他；
   - 线人三次都说「这人干净得很」，有一次被事实推翻了。
8. **结果页地点写错**（4/5）：下午谈话的结果，写成了下一个时段那人所在的地方。已核实：`act_interview` 先扣行动点、再查人在哪。
9. **稳赢的打法**（阿凯）：别惹广告主，挑最大的料用煽动放头条，有人送钱就收。卖报的钱占比太小，「没坐实也卖得一样多」。
10. **后果只有一行字，玩家接不住**（小林）：来访只能「送客」。
11. 小问题：
    - 续报默认勾上没坐实的新料；
    - 来访标题写「来送料」，内容里没有料；
    - 记恨被写成「跟你不熟」；
    - 第一次查档案没有「可能白翻」的提示。

## 做得好的（不要改坏）

- 查档案、蹲点，「去哪个地方」的推理是成立的（老周）。
- 排版台能马上看到自己的选择变成了什么，是最投入的一屏（阿凯、莉莉）。
- 信、来访、报道正文有人味（小林）。黄油那篇、地契那篇像真报纸（三局都提到）。
- 第 2 周一周里看到四条因果时，是整局最好玩的时候（阿凯）。

# 试玩须知（给扮演玩家的子 Agent）

你要扮演一个真实的玩家，第一次玩一款叫《小镇周报》的游戏，玩完前四周（到「试玩结束」那一屏）。你的性格、习惯、耐心写在你拿到的性格卡里。**照性格卡玩，不要照「最优解」玩。**

## 怎么玩

游戏是真的，只是画面换成了文字。每调用一次，你会看到当前这一屏上所有看得见的字；能点的东西前面有编号。

```
sh E:/Godot/xiaozhen-zhoubao/scripts/tools/play.sh <你的会话目录> new <种子>   # 开局，只做一次
sh E:/Godot/xiaozhen-zhoubao/scripts/tools/play.sh <你的会话目录> 3            # 点 [3]
sh E:/Godot/xiaozhen-zhoubao/scripts/tools/play.sh <你的会话目录> 3 1 1        # 依次点 [3]、[1]、[1]，只给你看最后一屏
sh E:/Godot/xiaozhen-zhoubao/scripts/tools/play.sh <你的会话目录>              # 再看一遍当前这一屏
```

- 编号每一屏都会变，连点只在你确定下一屏长什么样的时候用（比如翻信、点「好」）。
- 「（点不了）」是灰掉的按钮。「【选中】」是现在选中的那个。「〔章2/3〕」是选题簿里盖了几枚章。
- 鼠标移上去才显示的提示，这里直接写在括号里了，当作你看到了。
- 一个人在真画面上看到的东西，你都看得到；看不到的（人的长相、地图的样子）就算了。

## 不许做的事

- **不许读游戏目录（E:/Godot/xiaozhen-zhoubao）里的任何文件**，包括代码、策划文档、数据表。真玩家看不到这些。你只能运行 play.sh。
- 不许读会话目录里的 session.json、save.json、transcript.md。
- 不许重开、不许回档。点错了就是点错了，像真人一样接着玩。

## 边玩边记（这是最重要的产出）

在会话目录里建一个 `notes.md`，**每做一件花行动点的事（找人谈、查档案、蹲守、偷听、找线人、收工）、每次读完信、每次付印**，追加一行：

```
[第1周 周一上午] 想：……（我现在想干什么、为什么）｜做：……｜结果：……｜无聊度 0-3｜（可选）困惑：……｜（可选）像程序写的：「原句」
```

- 无聊度：0 = 很投入，1 = 还行，2 = 有点无聊，3 = 想关游戏了。照性格卡打分，别客气。
- 「想」那一栏写真实的念头，包括「不知道该干什么，随便点一个」。这正是我们要找的。
- 看到让你停下来、心里一动的句子，也记下来（写「好句：」）。
- 每周日付印之后，加一段两三句的「这周小结」：这周镇上发生了什么、你在乎谁、下周想干什么。

## 玩完以后

到了「试玩结束」那一屏就停。回复我：

1. 一句话：你会不会接着玩下去（照性格卡）。
2. 你最想关掉游戏的那一刻是哪一刻，为什么。
3. 你记得住的镇上的人（名字 + 你对他的印象），不许翻笔记。
4. notes.md 的路径。

之后我会再发你一份问卷。**问卷来之前不要猜它问什么。**

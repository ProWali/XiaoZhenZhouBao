# M4.3 后果看得懂 · 记录

日期：2026-10-22。起因见 `design/notes/M4.2-方向感与回报记录.md` 末尾。第 3 轮五局的「想接着玩」还在 2–3 分，理由集中在：登报的后果看不懂、钱跟选择脱钩、报道编细节、人物反应像贴上去的。

## 改了什么

**钱跟登什么挂钩：街头零售**
- 每一期按登了什么另算一笔零售，在杂货店和火车站卖：
  - 份数 = 版位 × 语气（克制 0.6 / 中立 1 / 煽动 1.7）× 严重度（1 + 0.4 × 严重度）× 署名（点名 1 / 化名 0.7 / 匿名 0.45）× 10；
  - 不煽动的，还要再乘上公信力（0.5 + 公信力 / 100）；
  - 续报打六折。
- 煽动、点名、事情严重的放头条，多卖一百来份，合五块钱；克制、匿名的只多卖十几份。原来每期净利十块左右，登什么都差不多。
- 排版台每一篇写「这样登，街头大约多卖 N 份」，跟付印结算是同一个函数（`world.estimate_retail`）。

**账本一篇一篇写**
周一账本多一行「街头零售」，下面每一篇写：卖了多少份；怎么登的（语气、署名、附没附档案）；镇上信了、半信半疑、没什么说法，还是登错了被记下；谁对这一篇有什么反应。

**「附档案影印」真起作用**
不附档案，正文不写「据某处的记录」，「本报查到的」这类句子也不用；只有档案这一个来源的，写成「有消息人士称」。原来取消附档案，正文照样写「邮局留存的记录显示」。

**周六夜来访能回应**
- 求情的人：可以答应「不点他的名」，用化名、匿名都算守约；点了名，他记恨你说话不算数，好感、信任大跌。
- 上门威胁的人：可以「服软，这一期不登」；登了就是当面对着干，下周窗户会被砸。
- 守约、食言都在付印时结算，写进账本；排版台编辑这件事时会提醒「你答应过某某……」。
- 存档多一种操作 `promise`。

**蹲守**：确认框里再说一遍「选题簿里记着，这儿多在哪两晚有事」。

**找人谈**
- 结果后面注明是「对方是真不知道」，还是「知道，只是现在不肯说，过些日子再来」，或者「知道，可跟这件事沾着关系，不会说」。
- 线头不再指向拒绝过你的人。

**报道不编细节**（子 Agent 审稿）
- 30 个调查类事件逐句审过，中英同步：改写 234 句，加条件 114 句（绑到真正支撑它的碎片键上，比如 `ledger@archive`），删 29 句。分四类：
  - 编报社的动作：「本报写信去问州卫生局」；
  - 编细节：「保险公司下周来镇上」「杂货店卖三毛五」；
  - 替玩家下结论：「因为鸡不是自家养的」；
  - 编来源：「某位寡妇对本报说」。
- 17 个公告类事件（婚丧、春汛之类，镇上公开的事）里的点缀暂时留着。
- 还有一些句子跟当事人的职业对不上（比如「每天和工友一起上工」，可当事人可能是铁匠），列在待办里。
- 子 Agent 顺带发现：15 个标题列表中英长度不一样，下标是错开的。它改到的那几句已经按意思分开改了；这件事以后改标题时要注意。

## 第 4 轮子 Agent（M4.3 之后）

| 局 | 平均无聊度 r3→r4 | 提前收工 r3→r4 | 想接着玩 r3→r4 |
|---|---|---|---|
| 莉莉 10349 | 0.92 → 1.17 | 5 → 8 | 2 → 2 |
| 莉莉 11211 | 1.27 → 1.02 | 2 → 3 | 2 → 3（第一次说「会接着玩」） |
| 小林 | 0.90 → 0.98 | 1 → 1 | 3 → 4 |
| 阿凯 | 1.04 → 1.06 | 1 → 5 | 2 → 2 |
| 老周 | 0.96 → 0.95 | 0 → 0 | 3 → 2 |

平均 2.6 分，还没到 3.5。

- **有效的：**
  - 来访能回应，守约、食言的账本句子（「你答应过……报上却点了」），一看就知道后果；
  - 照选题簿写的日子蹲守，一蹲一个准；
  - 来信是故事型最在乎的部分。
- **问题：**
  1. **新手又卡住了。** 每件事都知道一点、剩下的知情人都不肯说时，周中钩子不触发：邮差风声只指向一条都不知道的事，补生又要求这周没东西可登。
  2. **阿凯找到新的稳赢：** 只登坐实的、化名、不得罪广告主、收钱不登，一期净赚十几块。煽动多赚的那点钱抵不上代价。
  3. **一字不差的复读**：同一条碎片从五个人嘴里说出来，原句一模一样。小林说这是最想关游戏的地方。
  4. **报道还在编：**
     - 标题写了玩家碎片里没有的当事人身份；
     - 「目击者不止一位」「有人对本报证实」，实际只有一个来源。
  5. **反应安错人：** 受害人被当成被曝光的一方，「想私下解决」「好像还没读到」。
  6. **推理型落空：** 厂主仓库烧了，厂里的人都说没听过。原因是「失火」这条碎片只给了 6 个随机的人。

## 第 4 轮之后改的

- 周中：镇上没有你没摸到的事，就补生一件（一周一件），不再看手上有没有能登的。
- 连着三回空手，结果页直接建议换个办法。
- 受害、旁观的角色被写进报道，好感上升，账本写「总算有人登出来了」，不再有曝光的反应。
- 线头不指向犯事的那一方。
- 收钱不登，每周两成可能传出去：公信力掉 6，来信说镇上在传。收钱的事写在来访画面和排版台的明处。
- 零售：
  - 基数翻倍；
  - 不煽动的还要看这一篇几成是坐实的（坐实越多卖得越好）；
  - 碎片多一条多卖一成。
- 广告主有气、这期不付广告钱，账本写明。
- 「附档案影印」只在这条真有档案来源时才能勾，亲眼看见的不算。
- 附和、确认一件已经记下的事，说「那件事」，不再把原句念一遍。「真不知道」「不肯说」的注明也改成几种说法轮着用，不再带括号（原来会多出一个句号）。
- 标题和当事人回应：登出的碎片里没提当事人，就不写他。
- 「目击者不止一位」「核对过」这类句子要这条真有两个以上的来源；删掉「有人对本报证实」「本报采访的一位某某证实」。
- 同一处蹲到好几件旧事，只说一句。
- 失火这条碎片全镇都知道（原来只给 6 个随机的人）。

- 敢说 18 / 0 / 9 / 3
- 煽动 6 / 0 / 23 / 1

## 第 5 轮子 Agent（第 4 轮修整之后）

| 局 | 交谈问出新料 | 提前收工 r4→r5 | 想接着玩 r4→r5 |
|---|---|---|---|

| 莉莉 11211 | 13/44 | 3 → 0 | 3 → 3 |
| 小林 | 11/45 | 1 → 0 | 4 → 4 |
| 阿凯 | 15/39 | 5 → 0 | 2 → 2 |
| 老周 | 12/43 | 0 → 0 | 2 → 3 |

- 平均 3.0（第 4 轮 2.6）。五局第一次都没有提前收工，两个新手都说会接着玩。
- 这一轮四局中途被安全审查误拦（`reasoning_extraction`），都换模型续玩。原因多半是笔记格式要求写「在想什么、为什么」，已经改成「打算」。

**问题**
1. **当事人对自己的事「真不知道」。** 报道写的就是她的汇款，她却不知道；牧师不知道自己在南边养家。原因是碎片的主人不在知情人里。
2. **按职业推理落空**（老周）。「酒喝瞎过人」去问医生，医生不知道。
3. **新的稳赢**（阿凯）：坐实 + 附档案 + 煽动点名，钱、订户、公信力一起涨。
4. **广告主生气没有原因。**
5. **报道编采访：**
   - 只聊过别的事，稿子就写「否认」「拒绝回答」；
   - 标题点出碎片里没有的卖家；
   - 「目击者不止一位」又出现了。
6. **补满三枚章的旧碎片登不了续报**，排版台也不说为什么。
7. **多勾一条没坐实的，「多卖」反而少了**，看不懂。

## 第 5 轮之后改的
- 碎片的主人一定知道这条，犯事的一方知道这件事的全部实情（谣言除外）。
- 按事情的性质找人。碎片里有「病、伤、瞎、药」，诊所的人会听说；还有：
  - 「账、款、合同、地契」→ 镇公所；
  - 「信、汇款」→ 邮局；
  - 「酒、牌」→ 酒馆；
  - 「面粉、黄油、货」→ 杂货店；
  - 「火车」→ 火车站；
  - 「木料、工钱」→ 锯木厂；
  - 「孩子」→ 学校。
- 煽动的报道，每篇扣公信力从 1 加到 2。
- 记下谁为哪篇报道生气（当事人和他的家里人、朋友），广告主不付钱时账本写「还在为《某篇》生气」。
- 报道回应：只认就这件事问出过东西的采访；只聊过天不再写「拒绝回答」。
- 标题全滤光时，退回不提当事人的那几条。
- 亲眼看见又有别的来源，用一般的「对得上」，不写「目击者不止一位」。
- 坐实续报：登的时候没坐实、后来坐实了，可以再登一篇续报。
- 排版台估零售时写明「其中 N 条还没坐实，正经读者少买」。
- 线头不指向还在生你气的人。
- 邮差不跟你说话的那几周，不捎风声。
- 说话人本人就在碎片说的地方做事（医生讲诊所的记录），算亲口说自己的事。
- 来信不再说「看见他的名字登在报上」（化名时不对）。

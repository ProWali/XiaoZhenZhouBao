# M4.2 方向感与回报 · 记录

日期：2026-10-22

## 为什么做

M4.1 外部试玩（两位朋友）和第 1 轮子 Agent 试玩（五个性格，见 `design/agent_playtest/第1轮-基线.md`）说的是同一件事：

- 没有 ★ 的时候不知道干什么，第 2、3 周进入空转，一连好几天直接收工；
- 「谁会知道」推不出来；
- 文字露出程序的痕迹；
- 报上登的人，当面谈话时不接自己身上的事。

## 改了什么（前半，提交 080d67e）

**找人谈：先看知不知道，再看肯不肯说**

- 原来先掷「愿不愿意说」，再看「知不知道」。「含糊几句」既可能是知道不说，也可能是根本不知道，玩家分辨不出来，推理推不下去。
- 现在：
  - 手上没有料的人，明说不知道，有时给线头；
  - 手上有料的人，再看肯不肯说。不肯说要讲出原因：是当事人、是当事人的家里人或朋友、嘴紧、还在生报社的气、还信不过你；
  - 选题簿在这件事下面记一笔：「某某知道点什么，但不肯说（原因）」。
- 话头这一句对方没听过、但同一件事他知道别的，他会说出别的（「你说的那句我没听过，不过这件事……」）。
- 犯事的一方不会自己招认。说出来的碎片里出现说话人自己的名字时，改成「我」。

**谁会知道：事情出在哪儿，那儿的人就知道**

碎片里写到的地方、要去蹲守的地方、档案所在的地方，在那儿做事的人会知道。管档案的、管事的排在前面，不靠随机。例子：教堂门口贴的预告，牧师会知道。

**★ 常有**

- 每周一，镇上如果有还没登、玩家一条都不知道的秘密，邮差捎一句风声，附一个线头。只说去找谁，不说是什么事。
- 线头不再指向一整天待在家里、玩家见不到的人。
- 仇人来信说「另一半你想听就来找我」，现在只有他真知道更多时才会写，而且会进线头页。
- 线头页写明这个人知道的是哪件事。不是你正在查的那件，就写「一件你还不知道的事」。

**选题簿标出问没问完**

- 每件事下面写「镇上还有人知道这件事里你没听过的」，或者「能问的人大概都问到了；还没到手的，只能去翻档案或者蹲守」。
- 找人谈时，话头列表把问完的事放到最后，标上「这件事能问的都问过了」。

**蹲守能推**

- 每个蹲守点一周固定两个晚上（事件生成时定好），选题簿写明是哪两晚。
- 知道这件事的玩家蹲错了晚上，会被告知「不是今晚，听说是周四、周六」。
- 选题簿提示去蹲的地方（火车站、镇公所、邮局、杂货店），晚上的地图上都能点了。

**当面谈话接这个人自己的事**

见面头一句：

- 报上登过他家的喜事丧事：「报上那几行字，家里人都看到了」；
- 他是被登的人：冷淡，或者格外客气；
- 他是事情里的另一方：「报上登了以后，总算有人问起这事了」；
- 家里有喜事要办；
- 还在记恨报社。

一个人一周只说一次。

**一致性**

- 结果页地点：原来下午谈话写成了对方下一个时段所在的地方，现在先查地方、再扣行动点。
- 线人：犯事的一方也算这人的事，不再把偷猎的人说成「干净得很」；这人的事你都知道了，就说「你不是都知道了吗」。
- 上过门、知道你在查的人，一定读到了报道（原来会出现上门求过情、两周后还「没读到」）。
- 被报道夸过的人，当周不会写信退订（原来邮差说她满意，她又来信退订）。
- 来信八周内不重复别人写过的句子；同一封信再读一遍，还是原来那几句。
- 来道谢的人没带料，标题写「来道谢」，不写「来送料」。
- 求你别登、给你塞钱的，只能是犯事的一方（原来受害的人也会上门塞钱）。
- 「放出话来想私下解决」，不再写「托人带话」（原来出现过邮差自己给自己带话）。
- 报道正文：
  - 「本报看见的」「本报查到的」，只在这条真是亲眼看见、真是档案上查到时才用（引擎多了「碎片键@来源」）；
  - 「本报去过他家两回」「托人捎了话」「这一周都不在镇上」这类编出来的话从备选里删了。
- 官司从三周后到改成两周后到，四周的试玩里看得到。
- 结果页的章数和选题簿一致。

**文字版试玩工具**

点不了的东西也编号，编号不再跟着挪。

## 还没做的（留给后半）

- 稳赢的打法（别惹广告主，挑最大的料煽动着登，有人送钱就收）：钱主要靠广告，卖报占比太小。要跟 M5 ③ 的遗留问题（谨慎派太有钱）一起调。
- 来访只有「送客」一个选项，玩家接不住后果。
- 试玩结束页：「这四周你改变了谁」。
- 邮差风声一周最多一条，够不够等第 2 轮看。

## 第 2 轮子 Agent（前半之后，同性格同种子）

| 局 | 交谈问出新料 r1→r2 | 平均无聊度 r1→r2 | 提前收工 r1→r2 | 想接着玩 r1→r2 |
|---|---|---|---|---|
| 莉莉 10349 | 8% → 30% | 1.60 → 1.30 | 10 → 8 | 2 → 2 |
| 莉莉 11211 | 29% → 29% | 1.45 → 1.17 | 9 → 6 | 2 → ? |
| 小林 | 17% → 23% | 1.86 → 1.49 | 2 → 0 | 3 → 3 |
| 阿凯 | 17% → 24% | 0.87 → 0.96 | 0 → 0 | 2 → 2 |
| 老周 | 18% → 33% | 1.10 → 0.58 | 0 → 0 | 2 → 2（「第一周知道干什么」升到 4） |

**有效的地方**
- 推理型变化最大：「谁会知道」推得出来了，有理由的拒绝是它最喜欢的设计；
- 蹲守照提示去，2 次中 2 次；
- 见面先说自己的事，让故事型第一次觉得「报纸改变了谁」。

**没解决的**
1. **新手还是会空转。** 根子是一件事只有两三条料，一两天就挖完了，选题簿里全标成「问过了」，而邮差的风声一周只来一次。
2. **新加的话变体太少。** 一重复就更出戏，「你们写的那些，我都读了」隔两周又说了一遍。
3. **报道编来源、写「本人没回应」。** 当事人前一晚刚上门，稿子还这么写。
4. **线人和亲眼看见的对不上**（老周最在意）：查的人是收赃的一方，不是犯事的一方。
5. **撤广告没有原因。**
6. **「问过了」这个标签误导人。** 标着问过了，去问照样能加章。

## 后半（第 2 轮之后）

- **周中补钩子。**
  - 周二到周五，玩家手上没有找得到人的线头、选题簿也都问完了，邮差路过时指一个人。
  - 这周手上要是没东西可登，就补生一件事，一周最多一件。
- **问没问完写清楚。**
  - 话头标「镇上能打听到的你都知道了，再问只能多一个人作证」；
  - 选题簿分成「还有人知道」「还能翻档案或蹲守」「都知道了」三种。
- **短句不连着重复。** 所有界面短句记住最近用过的，先挑没用过的。变体扩了一倍：闲聊 14 句，附和 6 句，拒绝每种 3 到 4 句，见面头一句每种 3 到 4 句。来访四周内不重复同一段，来信八周内不重复（前半已做）。
- **说自己的事用亲口的口气。** 碎片里说的就是说话人自己，用「瞒也瞒不住」这类说法，不说「我听说」。
- **上门解释的人讲出一条**自己知道、又不往自己身上揽的料。
- **报道回应对得上。**
  - 当事人上过门：「来过报社」；
  - 当面拒绝过：「拒绝回答」；
  - 都没有：「本报没能联系到」。
- **线人。** 在事情里有任何角色都算这人的事，收赃的店主不再「干净得很」。
- **谣言凑不满三枚章**（最多两枚半），「坐实」的事不会再被人来信说没发生过。
- **酒馆。** 酒客多半说你还没听过的事，不说自己的丑事，醉话走样从 25% 降到 15%。
- **撤广告。** 施压连带撤掉的广告，账本上写明是谁让谁撤的。
- **文字改准。**
  - 化名的说明改成「伤得轻一些，当事人照样会记恨」；
  - 熬满两夜以后去酒馆，不再同时写「明天照常」；
  - 晚上的提示改成「亮着名牌的地方都可以蹲守」。
- **修的 bug：** 周中补生的事件没有「今晚」字段，蹲守报错，自动玩家原地打转。自动玩家加了「三步没进展就收工」的保护；问过四个人还坐不实的料，不再追。

### 平衡（52 周，每种 30 局，跑满 / 破产 / 停刊 / 被毁）

| 策略 | 前半 | 后半 |
|---|---|---|
| 谨慎 | 27 / 0 / 0 / 3 | 26 / 0 / 0 / 4 |
| 敢说 | 22 / 1 / 7 / 0 | 13 / 1 / 9 / 7 |
| 煽动 | 2 / 2 / 19 / 7 | 4 / 2 / 14 / 10 |
| 软新闻 | — | 30 / 0 / 0 / 0 |
| 随机 | — | 13 / 12 / 0 / 5 |

「敢说」（两枚章就点名煽动着登）掉得多。原因是酒馆现在多半说新料，谣言也坐不实了，它登出去的半真半假多了，结的仇也多了。到 43% 存活，算有风险、不算稳输，先留着。煽动派稳输、谨慎派太有钱，这两个老问题还在，留给经济那一轮。

还没做的：周六夜来访只有「送客」一个选项；试玩结束页「这四周你改变了谁」；广告谈回来的路；报道里事件自己写的场面细节（「本报写信去县法院」这类）要逐条查。

## 第 3 轮子 Agent（后半之后）

| 局 | 平均无聊度 r1→r2→r3 | 提前收工 r1→r2→r3 | 交谈问出新料 r3 | 想接着玩 r1→r2→r3 |
|---|---|---|---|---|
| 莉莉 10349 | 1.60 → 1.30 → 0.92 | 10 → 8 → 5 | 32% | 2 → 2 → 2 |
| 莉莉 11211 | 1.45 → 1.17 → 1.27 | 9 → 6 → 2 | 34% | 2 → 3 → 2 |
| 小林 | 1.86 → 1.49 → 0.90 | 2 → 0 → 1 | 22% | 3 → 3 → 3（第一次说「会接着玩」） |
| 阿凯 | 0.87 → 0.96 → 1.04 | 0 → 0 → 1 | 32% | 2 → 2 → 2 |
| 老周 | 1.10 → 0.58 → 0.96 | 0 → 0 → 0 | 19% | 2 → 2 → 3（「看得出影响」4 分） |

**判断**
- 方向感这一块基本立住了。新手提前收工从 9–10 次降到 2–5 次，故事型的无聊度减半，推理型「第一周知道干什么」稳定在 4 分。
- 「想接着玩」还在 2–3 分。五局给的理由已经从「不知道干什么」换成了下面这几条：
  1. **登报的后果看不懂。**
     - 语气、署名、档案三项全用默认。
     - 撤广告、窗户被砸的原因和对策都没写。
     - 取消「附档案」后，正文照样写档案来源。
  2. **钱跟选择基本脱钩**（阿凯）：每期净利约 10 块，跟登什么关系不大。
  3. **报道编细节、编来源**（三局）：这些是事件模板里写死的场面细节，不看玩家查到了什么。要逐个事件检查。
  4. **人物反应还像贴上去的**（老周、小林）：
     - 拒绝理由跟这个人当天的立场打架；
     - 一句概括吞掉了谈话内容（「讲了一件旧事」）；
     - 来访只有「送客」一个选项。

**第 3 轮之后顺手改的**
- 剩下的知情人这周都拒绝过你，也算「问完了」，周中钩子会接上。
- 当面谈过的当事人，报道写「拒绝回答」，不写「没能联系到」。
- 短句一组没轮完之前不重复。
- 删掉「我不在那一片走动」这句（跟人设打架）。
- 「我不在背后说他」改成不分男女的说法。
- 「上回你们怎么写的我还记着」只适合被写过的人，改成泛指。

## 下一步（M4.3：后果看得懂）

按五局的共同意见排：
1. **排版台和周一账本把后果说清楚：**
   - 这期的语气、署名、档案分别带来了什么，份数多了几份、谁生气了；
   - 撤广告、砸窗写明因为哪一篇。
2. **「附档案」的开关真起作用。** 不附档案时，正文不写档案来源。
3. **周六夜来访加回应选项：**
   - 解释的人可以「听他说完」（记下他的说法）或「请他走」；
   - 求情的人可以答应不登名字。
4. **报道事件模板里的场面细节逐条审**：只写玩家查到的，或者明说是本报推测。
5. **钱要跟选择挂钩**：卖报收入的比重、大报的花钱处。这一条和 M5 ③ 的遗留问题一起做。

# M4 垂直切片 · 记录

日期：2026-10-21

## 目标

策划案七版：完整表现的第 1 到 4 周，可发给外部试玩，收集「看不懂模拟」的反馈。

开工时定的过关标准：

1. 我自己从头走完四周，不看代码也知道每一步该干什么。
2. 自动走查跑四周，每一屏截图，不崩、没有空文本和错位。
3. 原有测试保持全绿。

## 做了什么

### 画面

- 16 色调色板（赭石、石板蓝、砖红、瓶绿、米白），`scripts/ui/palette.gd` 和 `scripts/tools/pixelize.py` 各存一份，改一边要改另一边。
- 17 张底图：镇子地图、编辑室（夜里一张，白天换窗玻璃一张）、13 处地点内景（两个农场共用一张）、主菜单远景、印刷夜。先生成草图，再用 `pixelize.py` 缩到 640×360、压进调色板。原图和请求记录在 `design/art_src/`，共 187 积分。
- 生成图里的旗画成了法国国旗（地图和镇公所内景各一处）。策划案规定不指明国别，`fix_flags.py` 把旗面改成单色。以后重新生成底图，要先跑 pixelize，再跑 fix_flags。
- 人物：头像 32×32、全身小人 14×30，按居民的编号哈希、性别、年龄、职业拼（`portrait.gd`）。不碰 world.rng。审美术用 `scripts/tools/portrait_sheet.gd` 出一张全镇的头像表。
- 字体三套，都是 OFL：界面用 Fusion Pixel 12px；报纸用思源宋体（Regular / Black）；选题簿和来信用霞鹜文楷。后两套用 `subset_fonts.py` 裁成「GB2312 全部汉字 + 项目里出现过的字」。加了新界面文字，要重跑一次裁字。
- 画面与材质的对比照策划案六版：镇子是像素画，报纸、选题簿、信是真实字体。

### 声音

- 16 个音效全部由 `scripts/tools/gen_sfx.py` 程序合成，没有第三方采样，版权归项目。还没有人听过；子代理认为门轴的吱呀声、投信口和鸟叫最可能听着假。
- 三首钢琴配乐是 Lyria 生成的定调草稿，不循环，弹完就安静。按策划案十一版，发售版要照草稿重写成 MIDI。

### 界面

| 界面 | 说明 |
|---|---|
| 主菜单、新局设定、设置 | 报名、主编名、种子、铁人、自杀后果开关（默认关）；音量、全屏 |
| 编辑室 | 枢纽。热区：门（出门）、桌上的选题簿、抽屉（线人）、日历（收工）、印刷机、广告板。可变层见下 |
| 镇子地图 | 15 处地点，名牌上写这会儿在那儿的人数；晚上只开酒馆和四处蹲守点，整张图压暗 |
| 地点内景 | 在场的人站在前景，点人选话头；有档案的地方可以查档案 |
| 选题簿 | 摊开的本子。按事：碎片、来源、印章（三枚算坐实）、还能去哪查；按人：头像、家人、关于他的事、从他那儿听来的事 |
| 周六夜来访 | 来访者站在门口，私下交易可以收或不收 |
| 排版台 | 左边挑事、选碎片、语气、署名、证据、三选一标题、重写一次；右边是真实版式的报纸，改什么都立刻重排；可以看清样 |

| 周一早上 | 门缝下的信一封封读，最后一页是上期账本 |
| 试玩结束 | 前四期头条，回传试玩记录的路径 |

编辑室可变层（`office_layers.gd`），都从模拟状态读，不另存：碎窗（当周）、木板封窗（之后三周）、门缝下的信、窗外人影（有人要来砸窗放火，或刚被重度曝光、脾气冲的人还在镇上）、撤空的广告栏、桌上的传票、冬天窗上的霜、火烧过的墙。

### 模拟层的改动

- `world.preview_issue()`：排版台的预览。付印时前一篇会记下用过的句子，影响后一篇的措辞，所以整期按付印顺序一起预览，预览完把文本记忆还原。新增测试：6 个种子 × 12 周，80 篇预览和付印逐字一致。
- `flags.window_week`：砸窗那一周，给可变层用。
- 修了一个潜伏的 bug：候选标题不足三个而玩家选了第三个时，故事日志那一行会越界。新测试撞出来的。

### 存档与试玩记录

- 存档照旧是种子加操作日志，外面包一层画面层的进度（信读了没有、来访名单、排了一半的版面）。铁人模式下每一步自动存。
- 每次试玩写一份 `user://playtest/session-时间.jsonl`：看了哪一屏、做了什么、花了多久。不含个人信息。结束页给出路径和「打开文件夹」按钮。

## 这一轮的决定

都已追加到策划案九版的决策记录。

1. **画面先用生成草图压成像素图。** M4 要回答的是看不看得懂，画面够用、统一就行。发售前要重新确认这批图的使用授权，并在 Steam 页面如实申报 AI 生成内容。授权有问题就按同样构图手绘重做。
2. **「镇上在说什么」提前放进 M4**，形式是账本上「邮差顺嘴说了几句」。原定等试玩反馈说看不出影响再加。真人试玩是最贵的资源，不该拿去验证一个我已经认为会失败的版本。
3. **公信力不显示数字。** 账本上只写「镇上怎么看这份报纸」（六档）和比上周好了还是差了。现金和印数照常是数字，账本上本来就该有。
4. **排版默认化名、默认附档案。** 点名的伤害和报复最重，不该是新手不知情时的默认。
5. **线人放在编辑室的抽屉里**，花三块钱和一个行动点，只列见过或听说过的人。第一周周二早上提示一次。
6. **民居暂时进不去。** 模拟层没有民居相关的行动，做了也只是空房间。
7. **窗口默认 1280×720**（两倍），F11 全屏（1080p 下三倍）。

# M4.1 取料 · 记录

日期：2026-10-22

## 老板的试玩

老板自己玩了一局（种子 25274），玩完四周，前后约 25 分钟。试玩记录加存档逐步重放（新工具 `scripts/tools/replay_report.gd`）得到下面的情况：

- **交谈几乎全落空。** 31 次交谈里，对方手上有玩家不知道的事的只有 3 次。其余都是「聊了聊天气」「想不起来了」。真正的料来自偷听、查档案和匿名信。
- **第一周没去找邮差。** 首周保底是把半公开的事告诉邮差，前任主编的信也提了邮差。但他先去找一个农户聊了两次，都落空；周三以后放弃，周四到周六连着三天直接收工。
- **第四周空着付印。** 那周他新听到两条关于书记员酗酒的事（诊所记录、醉后打人），可这件事第二周已经登过。排版台把登过的事整件藏掉了，新料登不了。
- **四周只生出两件秘密事件。** 后果也轻：公信力从 50 到 53，周六来访四周一共 1 人。

画面这一层是通的：他每一屏都用到了，在选题簿、清样、读信上停留的时间都不短。坏的是取料：主要动作（找人谈）几乎不产出，玩家也无从知道该找谁。这正是策划案八版担心的「模拟做得越深，玩家越看不见」。**这一版不能发给外部试玩者，先修。**

## 量出来

新工具 `scripts/tools/yield_probe.gd`：模拟一个不懂门道的新玩家（有线头就找线头上的人；没有就去人多的地方随便找一个人；每周熬一夜；不查档案、不找线人），跑 30 个种子的前四周。

| 指标 | 改前 | 改后 | 目标 |
|---|---|---|---|
| 交谈既没料也没线头 | 75% | 37% | ≤ 45% |
| 每次交谈平均问出 | 0.25 条 | 0.37 条 | ≥ 0.5 条（**未达到**） |
| 顺着线头找人，每次问出 | — | 0.79 条 | |
| 每周能登的事 | 1.33 件 | 2.15 件 | ≥ 2 |
| 一件能登的都没有的周 | 16 / 120 | 0 / 120 | ≤ 3% |
| 第一周就摸到秘密事件 | 15 / 30 | 30 / 30 | ≥ 80% |

「每次交谈 0.5 条」没到。剩下的落空主要是新玩家无视线头、随机找人；只要顺着线头走，每次接近 0.8 条。这一条留给真人试玩检验，不再往上堆数值。

## 改了什么

模拟层：

1. **线头。** 交谈落空（含糊、闲聊、不知道）时，对方有机会给你指一个人：一个知道某件你还不知道的事的人。有话头时优先指向同一件事；对方更常指自己认识的人；不会指当事人来讲自己的秘密；整天待在家里、玩家见不到的人很少被指。顺着线头找来，对方更愿意开口，说的多半就是那件事。线头三周后作废。
2. **半公开的事，当事人身边总有人听说过**：多三个同事、一个朋友知道。
3. **随便聊也能帮你坐实。** 对方没有新料、但说起一件你听过的事时，算一个新来源，选题簿上多盖一枚章。
4. **事件保底。** 镇上在跑、还没登过的秘密少于两件时，一定再生一件。
5. **续报。** 事件记下登过哪些碎片；登过的事又有新料时，可以再登一次续报。

界面：

- 选题簿新增「线头」一页；地图名牌和地点里，线头上的人标 ★；交谈结果里写明「记下线头」；编辑室底下的提示有线头时直接说去找谁、这会儿在哪。
- 排版台列出有新料的已登事件，标「续报：N 条新料」，默认只勾新料。
- 第一周的提示直接说「先去邮局找邮差」。
- 查档案前，如果选题簿里没有线索指向这里，提醒「翻了很可能白翻」。

## 平衡

52 周、每种策略 10 局，改前（M4 提交）和改后对照：

| 策略 | 改前：跑满 / 破产 / 停刊 / 被毁 | 改后：跑满 / 破产 / 停刊 / 被毁 |
|---|---|---|
| 谨慎 | 6 / 2 / 0 / 2 | 7 / 3 / 0 / 0 |
| 煽动 | 2 / 6 / 0 / 2 | 1 / 0 / 5 / 4 |
| 只登软新闻 | 10 / 0 / 0 / 0 | 10 / 0 / 0 / 0 |
| 随机 | 6 / 4 / 0 / 0 | 5 / 4 / 0 / 1 |

谨慎打法基本不变。煽动打法更难了：能登的料多了，官司也多了，死因从破产变成停刊。「煽动几乎稳输、只登软新闻稳活（但发行量掉到五十几份）」是改动前就有的问题，策划案十二版说任何策略稳赢稳输都是设计 bug，留给 M5 和平衡一起调，不在这一轮动。

# M4.1 · 老板第二次试玩

日期：2026-10-22。种子 35235，约 22 分钟，玩完四周。重放存档逐步看。

## 和预期对比

| 指标 | 探针预期 | 实际 |
|---|---|---|
| 交谈既没料也没线头 | 37% | 30%（33 次里 10 次） |
| 每次交谈平均问出 | 0.37 条 | 0.30 条 |
| 线头 | | 13 个，大多顺着找了 |

取料达到预期。玩法转起来了：顺着线头查出「炸鱼」和「偷鸡」，偷鸡登了三期续报；渔夫被登以后买单程票走了；有人上门塞十块钱求不登，没收；窗外站过人；来信里有要求更正的、替当事人求情的、退订的。

## 发现的问题（都已修）

1. **公信力从 50 掉到 37，主要是默认替他选的。** 第二周头条混进一条匿名信里的说法（0 枚章，不实），第三周混进一条当事人撒的谎（1 枚章）。排版台默认把碎片全勾上。改成默认只勾两枚章以上的；没坐实的标红「【没坐实】」，旁边写一句「没坐实的也能登，卖得一样多；登错了，镇上会记住」。
2. **顺着线头找到人，常常白跑。** 他到了线头上的人跟前，拿别的事当话头问（多半是人人皆知的婚礼），对方说不知道，又指下一个人，绕成连环。改成：顺着线头来的，对方开口的概率再高一截（+0.4），问的不是那件事也会把他知道的那件说出来。话头列表去掉软新闻。
3. **夜里反复蹲到同一幕。** 河边蹲了五晚，四晚看见同一个人拔鸡毛；熬夜太多丢了四个上午，游戏没说为什么。改成：再看到同一幕明说「跟上回一样，没有新东西」，不算新料；睡过头的那天早上编辑室提示原因。
4. **撒谎的逻辑错了。** 丢鸡的失主自己对你说「鸡是自己卖的，对外说是丢了」。撒谎只来自犯事的一方（或其家人），不拿关于自己的谣言撒谎。
5. **文字。** 「摇头：这个我真不知道」后面紧跟「摇头：这事你得问……」，线头的句子改成接着上一句说的口气；当事人（含失主）不再用自己的全名讲自家的事当闲话。

探针复测：按线头找人每次平均 0.89 条（原 0.79），其他持平。测试全绿，走查（种子 35235）0 报错。

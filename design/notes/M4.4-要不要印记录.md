# M4.4 要不要印

## 起因：老板第三次试玩（2026-10-22 晚，M4.3 版，种子 75103）

存档 user://playtest/session-20261022-211849-save.json，34 分钟打完四周，提前收工 1 次。

看到的：
- 每周一件硬新闻，周三周四挖完，后半周随便聊。第 4 周周三到周六 8 次只出 1 条新料。
- 排版全收默认：头条四周都是软新闻，硬新闻全化名，语气只用过一次克制，从不点名，每周排版约一分钟。
- 后果多是「很满意」「好像还没读到」「要来当面谈谈」。发行 186→195，现金 41→57。
- 偷鸡登了三期，第 2、3 周几乎没新料。

老板的回答：
1. 化名加中立：怕惹事，不知道会有什么后果。
2. 偷鸡又登：没注意登过了；也没别的可登。
3. 没去找目击者凯斯·索恩：以为「找本人大概率不会承认」也适用于他。其实他是 witness，问了能再坐实一条。
4. 数字会看但不关心：没压力，没感觉到游戏想表达什么。
5. 想不想玩第 5 周：没太多感觉，反问我的预期。

顺手修了：结尾补句号不再补在「。）」后面；线人那句「他的事」改「那人的事」（当事人可能是女的）。

## 判断

策划案的核心张力是「我知道这件事，但要不要印」。这局四周里一次都没出现：
- 没人在付印前来求情或施压，默认选项（化名、中立）也没有代价，所以没有犹豫；
- 后果只有一句话，看不出谁的日子因为这篇报道变了；
- 钱一直在涨，「多卖几份」没有诱惑力；
- 一周只冒一件事，后半周空着，节奏也撑不住。

取料这一层已经立住了（老板原话：目的性好多了），下一步要补的是「印」这一端。

## 计划

1. **付印前有人找上门**：你在打听谁，谁就会听说。前四周保证至少一次当事人或亲友在周六夜来求情、施压或塞钱，最好碰上广告主或熟人（锯木厂、邮差）。
2. **排版台把账算在明处**：每个选项旁边写清这一篇会卖多少份、当事人会知道是谁写的吗、可能怎么报复。化名也有代价（镇上半信半疑、卖得少）。
3. **后果落到人身上**：登出去一两周内，当事人的处境要看得见地变：丢工作、搬走、停卖、辞职，家人来信。换掉「好像还没读到」。
4. **周中不断档**：同时在跑的秘密从一件提到两件，周中再冒一件。
5. **看得懂的小修**：传闻里点了名的目击者标成线头（「他是亲眼看见的，去当面问」），跟当事人分开；没新料的续报在排版台写明「上期登过，这次没有新东西」，硬登读者会来信说炒冷饭。
6. **钱要紧一点**：先看第 2 条做完后的数字再定，目标是「多卖几份」开始有分量。
7. **名字认得住**（老板补充：外国名字难跟人对上）。这局的名单里，卡维·瑞恩/卡维·卢比、诺维·马斯/诺维·吉斯、萨维·泰塔/萨维·米娜/萨维·汉克 都是同一家人，但中文写成「姓·名」，同姓的人前两个字一样，读着像同一个人；还有诺顿、诺彻、诺维这种开头一样的名字。
   - 中文改成「名·姓」（音译名的习惯写法），一家人共用后半截，不同的人开头就不一样；
   - 生成时避开开头同音的名字（诺顿/诺彻/诺维这种只留一个）；
   - 名字出现的地方一律带职业，前两周常露面的人（邮差、镇长、医生、警长、牧师、酒馆老板）用「邮差哈德」这类叫法；
   - 来信、来访、后果、结果框里有名字的地方配头像；
   - 中文版改用中文名不做：1935 年的教堂、警长、小镇是西式的架空背景，英文版也要同一套人。前三条做完还认不住再考虑。

## 过关标准（子 Agent 五个性格，同种子前后对比）

- 四周里每局至少一次付印前的施压或求情，玩家写得出当时为什么那样选；
- 新手性格至少有一篇改过默认选项（语气、署名或不登）；
- 玩完能说出一个因为自己的报道日子变了的镇民；
- 后半周随便聊、一无所获的次数比这局少一半。

## 做了什么

**名字认得住**
- 中文改「名·姓」，一家人共用后半截；一局里名不重复，不同的家不同姓，名和自己的姓不同头同尾（「维德·韦德」「拉森·拉斯」）。词表没动，但取名规则变了，同一个种子生出的镇子跟以前不一样。
- 来信落款、账本后果带职业（「邮差哈德·吉顿」）；来信左边配寄信人的头像和职业。

**周中不断档**
- 第二周起，每周开头至少两件没登过的事在跑（原来登完一件才补一件，等于一周一件）。
- yield_probe（30 种子 × 4 周）：每周能登的事 2.69 → 3.15 件；熬夜每次问出 0.18 → 0.37 条。

**亲历者线头**
- 碎片里点了名的受害人、目击者、在查的工头这类人（不是犯事的一方），玩家从别人嘴里听到这条时，记一个线头指向他；结果框里写明「他不是当事人，是亲身碰上这件事的人，当面问比听转述靠得住」。
- 当面问到亲历者算两枚章（转述一枚 + 亲历者两枚 = 坐实）。
- 顺着这种线头去找他，随便聊也会问到那一条。

**续报**
- 排版台分清「登完之后听到的新料」和「上回手上就有、没选进去的」：选题列表写「上期登过 · 没有新料」，编辑页写「这件事第 N 期登过」「硬登，读者会觉得是炒冷饭」。
- 真登了没新料的续报，下周一有读者来信说炒冷饭。

**付印前找上门**
- 拿某件事去问人：问的是当事人，他一定知道你在查；问的是他家里人、朋友、嘴碎的人，话容易传过去（基础两成，亲友加三成五，嘴碎加一成五）；随便聊问出料也有一点可能。
- 当事人知道了，周六夜找上门：自己来（求情、警告、谈条件，看脾气），或者家里人替他来求情（怕事的人七成是家里人来）。一件事只来一次。
- 第二周起，手上有坐实的料、当事人还没来过的事，每周六一半可能找上门；整局还没来过一次的，一定来一次。
- 家里人来求情，可以答应「不点名」或「这期不登」；守约、食言账本上写清是替谁求的；食言了伤心，不砸窗。
- 自动玩家 30 局 × 4 周：谨慎派每局都碰上，平均三次多。

**排版台把账算明**
- 编辑页顺序改成：语气、署名、附档案，紧接「登出去会怎样」，碎片放后面（原来预告在折叠线下面）。
- 「登出去会怎样」：镇上信不信；当事人（带脾气：怕事 / 精明 / 脾气冲 / 有势力）会不会读到、多半怎么反应（躲着你、上门解释、谈条件、砸窗、放火、撤广告并写明每周少多少钱、施压退订……）；会落到什么下场、几成把握；三种署名并排比：多卖几份、对方怎么反应。
- 和结算用同一套算法（world.forecast），只是不掷骰子。

**后果落到人身上**
- 四种「下场」事件：赔钱、收摊、要离镇、被叫去镇公所问话。加上原有的辞退、辞职、分居、检查员，30 件硬新闻里 28 件登出去以后有下场（暗中酗酒、鸦片酊成瘾这两件私人的事没有）。
- 下场的概率看怎么登的：点名 × 1、化名 × 0.7、匿名 × 0.35，附档案再乘 1.25；登的是假的没有下场。
- 下场本身是一件公开的事，下一期可以登；当事人不再「对报道很满意」。
- 下场落下的那周一，当事人家里人来信（「这就是你们登那篇报道想要的？」），吃了亏的一方也可能来信道谢。

**钱紧一点**
- 前任留下印刷厂旧账 40 元，每期付 5 元，八期付清；手头有余钱才付，付不起就欠着，不会因为这笔账破产。账本多一行「还旧账（还欠 N 元）」，前任的信里写明。
- 纵火重建的 60 元记进旧账，往后有余钱时还，不再一次扣光（原来开头被烧一次基本就死）。
- 自动玩家 30 局 × 8 周：谨慎派第 8 周现金 83 → 53，前八周没有一局破产或被毁（改之前被毁 3 局）。

**顺手修的**
- 结尾补句号不补在「。）」后面；线人那句「他的事」改「那人的事」。
- 英文匿名信一句超长，拆短。

平衡（52 周 × 30 局，跑满 / 破产 / 停刊 / 被毁；括号里是 M4.3 收尾时）：
- 谨慎 28 / 0 / 0 / 2（27 / 1 / 0 / 2）
- 敢说 11 / 2 / 16 / 1（14 / 0 / 14 / 2）
- 煽动 2 / 2 / 22 / 4（2 / 0 / 23 / 5）
- 软新闻 30 / 0 / 0 / 0（不变）
- 随机 14 / 11 / 4 / 1（21 / 6 / 1 / 2）

随机派破产多了：事多了、登得也多，加上开头还旧账。谨慎派一年后现金还是 700，旧账只管开头两个月，后面钱对好玩家照样没压力，仍留给经济轮。

**过关标准对照**
- 付印前的施压：五局里四局碰上，而且写得出为什么那样选（小林：不收店主的钱「他肯出钱就说明心虚」；牧师来警告，最后没登，「他南边有孩子，我下不去手」。阿凯：从煽动退回中立，因为预告写「可能放火」。老周：答应邮差不点名，后来「被叫去问话」那条会点他的名，又撤了，「不想换个方式食言」）。莉莉 11211 前两周几乎没拿到东西，没人找上门。**过。**
- 新手改过默认选项：莉莉 10349 每期改标题、两次不收钱，没改过语气署名；莉莉 11211 没改。两人都只扫了预告第一行（「我是赶时间的人」）。**没过。**
- 说得出谁的日子变了：五局都说得出，而且说得出从哪里知道的（赔钱、被叫去问话、收拾东西坐火车走、退订六年的报；家里人来信「这个家是真的难了」）。**过。**
- 后半周白跑：交谈问出新料从 2–6 次涨到 11–17 次（莉莉 11211 除外）。**过。**
- 算账型、推理型：「登出去会怎样」每次都看，是做决定的主要依据；阿凯说三种署名的对比「像 Papers, Please 里的规则手册」，预测和结果「一模一样」。

**问题**
1. **亲历者线头指向整天在家的人**（小林、莉莉 10349、阿凯）：寡妇、家眷白天不出门，镇上又没有民居可去，线头挂四周都「这会儿不在外面」。
2. **收钱照登没有代价**（阿凯的新稳赢）：两家各塞 10 块，收了照登，公信力反而涨。
3. **新手第一周卡在不肯说的亲历者身上**（莉莉 11211）：线头把她指到店主那儿，店主「等我想好了再说」，之后五次空手，开始混日子，第二周也一直收工。
4. **来访顺手点第一个就是「答应」**（两个新手）。
5. **预告和结果对不上**（小林）：勾掉写当事人的那条，他照样被叫去问话。
6. 只是上门警告、放下砖头就走的人，稿子写「来过报社，请本报不要刊登」（老周、阿凯）。
7. 信里设定不对：教师说「我不会写字」，寡妇说「我当家的不让我写」（老周）。
8. 偷听五局 6 次，一次新料都没有（阿凯、莉莉）。
9. 选题簿写「已登，有新料」，排版台写「没有新料、炒冷饭」（阿凯）。
10. 「赔出来」看不出赔给谁（阿凯以为是退贿赂）。
11. 「我自己经手的，没错」从受害人、目击者嘴里说出来，像在认罪（老周、小林）。
12. 没修的：报道还在编细节（「第二天还粘着几根白鸡毛」「本报追了几个礼拜」）；线人答非所问；信任值看不见，推理型分不清「推错了」「不信任我」还是随机；套话（「来过报社，说的话本报记下了」「对方知道，只是现在不肯说」）。

## 第 7 轮之后改的
- 在家做事的人（寡妇、家眷、赋闲的）下午六成出门办事（杂货店、邮局、教堂、诊所）。
- 收了钱还照登：给钱的人到处说，公信力扣 8，下周一来信说镇上在传；排版台的提醒写明这一点。
- 亲历者被问到自己碰上的事，肯说的把握加 0.35。
- 来访的「不答应」排第一个。
- 报道里没写到当事人，就不会有下场。
- 只有求情、塞钱的才算「请本报不要刊登」；上门警告的写成不愿回应。
- 来信加两个条件：识不识字、有没有配偶。
- 偷听多听一桌（3 → 4 人），每人开口的把握 0.5 → 0.65。
- 选题簿的「有新料」跟排版台用同一个口径（登完之后才听到的）。
- 「赔出来」改成「赔钱给吃了亏的人」。
- 亲口确认改成不带认罪味的几种说法。
- yield_probe：熬夜每次问出 0.37 → 0.47 条；一件都没有的周 1 → 0。

## 结论

过关标准四条都过了（新手改默认那条在第 8 轮过）。「想接着玩」第 7 轮平均 3.2（第 6 轮 2.8），第 8 轮两个新手都是 3。
还没解决、留给下一轮的：
- 新手前两周仍有连着空手的时候，酒馆偷听还是常常空手；
- 算账型看透规则以后没有挑战（钱对好玩家没压力，留给经济轮）；
- 推理型要「信任」看得见：推出来的人不开口，分不清是推错了还是不信任；
- 报道编细节、套话（「来过报社，说的话本报记下了」「登的是他的下场」每期都是这句）。

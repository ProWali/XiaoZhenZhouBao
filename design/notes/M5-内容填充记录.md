# 前半①：界面文字抽表、英文界面

- 设置里能切换简体中文 / English，当场生效。首次启动按系统语言选。模拟和语言无关（存档是种子加操作日志），所以随时能换。

# 前半②：续报体

- 续报（早先登过的事又登新料）原来和首报用同一套模板，读起来像把旧闻再登一遍。现在：
  - 标题三选一，两条是续报体（「偷鸡一事续闻」「More on the Stolen Chickens」），一条仍是这件事自己的；按周换。带当事人名字的续报标题只在点名时用。
  - 导语先交代前报（第几期、隔了多久）；点名时一半再提一句当时登了什么；不再介绍当事人。小栏续报不用场景导语，导语后跟「此事本报第几期曾有报道」。
- 抽检工具 `followup_sample.gd`。中英各读了几十篇，读起来是跟进报道。
- 顺带发现的模拟问题：
  - 后续事件（检查员上门）原来只在首报时掷骰。首报没附证据、续报附上了，就永远没有下文。改成首报续报都能引出，每种只掷一次。
  - 续报按首报的全额冲击当事人，被反复点名的人很快离镇，镇子的走向都变了（40 局里排污事件从 11 起掉到 3 起）。续报的冲击和发行量涨幅按首报的 0.6 算。
- 自动玩家也会登续报了（真人从 M4.1 起就能），批量平衡更接近真人打法。

# 前半③：平衡

策划案十二版：任何策略稳赢稳输都是设计 bug。加了续报以后，随机和煽动两种打法几乎必死，先看清死因再动。

## 改了什么（都是设计上说得通的，不是凑数）

| 改动 | 理由 |
|---|---|
| 登错的事：没坐实、语气不煽动的扣一半；煽动着登错的扣 1.2 倍 | 报上写了「尚待查证」和言之凿凿不是一回事。排版台上本来就写着「没坐实的也能登；登错了，镇上会记住」 |
| 没登错东西的一期，公信力往 40 回差距的 4% | 镇上会慢慢忘。原来公信力掉到 0 就永远是 0，改过自新没有出路 |
| 好感低于 0.45 的人每周回一点；广告主回得快（6%） | 原来得罪一次就是一辈子，广告主撤了就再不回来。小镇只有一份报纸，生意人过几个月还得登广告 |
| 一个人同时只打一场官司；小小提一句的很少告（轻 10% / 中 30% / 重 50%，原来一律 70%） | 同一个人为两篇报道连告两场，太机械 |
| 官司：登的是真事多半赢（附档案稳赢，没附 75%）；半真半假看名声；假的必输 | **原来真事没附档案时按公信力掷骰，名声差的报纸登真事也输官司**，这是错的 |
| 一年里输三场官司才停刊（原来是累计三场） | 早年的败诉不一直记着 |
| 煽动的报道，发行量涨幅只有一小部分看公信力 | 爱看热闹的人不管真假。煽动派的代价应该在官司、砸窗、退订上，而不是卖不动 |
| 只登软新闻的周：登两条以上读者每周掉 1%，一条 2%，没报纸 3% | 婚丧集市登满一版也算份报纸；镇上这类事多不多，各局不一样 |
| 自动玩家：煽动派、软新闻派收了钱就不登那件事；随机派钱少于 15 块不花钱查档案、找线人 | 收钱照登是两头得罪，真人不会这么干；随手乱来的人也看得见抽屉快空了 |
| 新增策略「敢说」：取料和谨慎一样，登两枚章以上的，一律点名、煽动 | 原来的煽动派把「语气煽动」和「什么都登」绑在一起，看不出煽动语气本身站不站得住 |

试过、又撤回的：每份纸墨 0.02 → 0.025、广告费随发行量最多涨 2 倍 → 1.4 倍。本意是让谨慎派钱别太多，结果谨慎派照样富，穷的几派先死光。撤回。

## 结果（10 局，跑满 / 破产 / 停刊 / 被毁）

| 策略 | 第一年（52 周，等于 Demo） | 两年（104 周，完整一局） |
|---|---|---|
| 谨慎 | 9 / 0 / 0 / 1 | 9 / 0 / 0 / 1 |
| 敢说（煽动但坐实两枚章） | 7 / 1 / 1 / 1 | 2 / 1 / 6 / 1 |
| 煽动（什么都登） | 5 / 1 / 4 / 0 | 0 / 2 / 8 / 0 |
| 只登软新闻 | 10 / 0 / 0 / 0 | 1 / 9 / 0 / 0 |
| 随机 | 5 / 1 / 1 / 3 | 0 / 6 / 1 / 3 |

改之前（M5②提交时）：第一年煽动 0、随机 0 跑满；两年里煽动、随机、软新闻全灭。

## 判断

**第一年（Demo）：过关。** 只登软新闻 10 局都活下来，但我不把它算「稳赢」：发行量从 180 掉到 70 上下，年度回顾一片空白，活着不等于办成了。

**两年：部分过关，如实记下来。** 煽动派和随机派两年里没有一局跑满。我的判断是这正是游戏要说的话（编造短期得利、长期代价）：一份两年里每周登一条以上假话、还点名的报纸，被告停或者被烧，是该有的结局。真人玩家会改，固定策略的机器人不会。但「敢说」派（煽动但有来源）两年 2 局活下来，说明煽动语气本身是一条有风险、走得通的路，这才是这条规矩真正要保的。

## 留到后面的

1. **谨慎派太有钱**：两年后现金 1300 左右，钱对好玩家没有压力（策划案说三条主数值要互相拉扯）。不能靠压所有人的收入来解决（试过，穷的先死）。需要只对大报起作用的花钱处：扩版、雇帮手、镇上指望报社出钱的事。M5 后半和内容一起做。
2. 煽动派死因八成是官司停刊。以后可以加「登更正启事」，让登错了的报纸有一条低头的路。
3. 这一轮所有改动是模拟层的，**外部试玩包（M4.1）不含这些**。试玩回来以后的判断要按 M4.1 的规则读。

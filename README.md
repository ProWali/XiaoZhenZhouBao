# 小镇周报

一款系统驱动的叙事模拟游戏。你是一座程序生成小镇上唯一一份报纸的主编，世界在后台自己运转，你登出来的每一个字都会反过来改变这座镇子。

- 引擎：Godot 4.7.2（可执行文件在 `E:\Godot\`）
- 原生分辨率 640×360，整数倍放大，16 色调色板
- 策划案：[design/策划案-v0.1.html](design/策划案-v0.1.html)

## 目录

| 目录 | 放什么 |
|---|---|
| `design/` | 策划案、氛围图、设计记录。导出时排除，不进游戏包 |
| `scenes/` | 场景文件 |
| `scripts/sim/` | 模拟核心：居民、关系、事实碎片、结算。纯数据，可无头运行 |
| `scripts/text/` | 文本引擎：事件模板、语法层、润色层 |
| `data/events/` | 事件模板（JSON） |
| `assets/` | 像素图、字体、音频 |

## 里程碑

M1 纸上原型 → M2 模拟核心 → M3 文本引擎 → M4 垂直切片 → M5 内容填充 → M6 Demo → M7 发售。详见策划案七版。
